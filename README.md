# 🚀 Featured Projects

## 🛒 urbancart – MERN E-Commerce Platform

A production-ready full-stack e-commerce application built using the MERN stack with secure authentication, online payments, product management, and a responsive shopping experience.

### ✨ Key Features

- 🔐 JWT Authentication
- 🛍️ Product Listing & Categories
- 🔎 Search, Filter & Sorting
- ❤️ Wishlist & Shopping Cart
- 💳 Razorpay & PayPal Integration
- 📦 Order Management
- 🖼️ Cloudinary Image Upload
- 📧 Email Notifications
- 🚦 API Rate Limiting
- 📱 Responsive Design

### 🛠 Tech Stack

**Frontend**

React 19 • Vite • Redux Toolkit • TanStack Query • Tailwind CSS • React Router

**Backend**

Node.js • Express.js • MongoDB • JWT • Cloudinary • Razorpay • PayPal
